# Methodology

Short explanations of each step of the project, with the figures they produce.

1. [Data loading](01_data_loading.md): three games in two formats, turned into one clean structure
2. [Player velocities](02_velocities.md): smoothing and removing physically impossible movement
3. [Pitch-control model](03_pitch_control.md): Spearman (2018)
4. [Validation](04_validation.md): an exact match with the reference code, and where and why the defaults differ
5. [Visuals](05_visuals.md): a single moment and an animated goal, and how to read them
6. [Match analysis](06_analysis.md): space and the scoreline, and where passes were played

Reference: [what is in the raw data files](data_notes.md).
